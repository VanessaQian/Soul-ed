# Soul-ed

A Java-based scheduling application that helps students organize their courses, assignments, and tests. Users can manage academic commitments, update schedule entries, and prioritize assignments based on upcoming deadlines.

**Features:**
- **Student Profiles:** Collect student names, grade levels, and student IDs.
- **Schedule Management:** Add courses, assignments, and tests; modify existing entries or remove them as needed.
- **Assignment Prioritization:** Sort assignments by due date and view assignments for individual courses.
- **Schedule Display:** Print course schedules and organized assignment lists.
- **Input Validation:** Validate user input and handle dates, times, and deadlines.

**Technical Highlights:** Uses object-oriented programming, classes and inheritance to represent courses, schedules, assignments, and tests. Implements data storage and retrieval, sorting, searching, and date/time handling to organize academic information.

**Naming of the Project:** A pun referencing the idea of selling your soul for academic performance, so your soul is it is **soul**-ed (sold)
